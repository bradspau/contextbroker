This bundle is a test decoy. It exists to prove that a candidate outside its scope is never
returned, however well its words match the topic. It is scoped to Switch-Decoy-9, a device that is
not in the demo topology, so no real request should ever receive it.

The text repeats the vocabulary of interface errors on purpose: interface errors, router, counters,
packet loss, link up, link down, flapping interface. A search by similarity on an interface-error topic
will rank this bundle near the top. The rule under test is that ranking by similarity does not decide
what a request receives. Only the declared scope does, and the scope here names one device that does
not exist.

If this text ever appears in an answer about Router-A or Router-B, the scope rule has failed and the
answer should be treated as wrong.
